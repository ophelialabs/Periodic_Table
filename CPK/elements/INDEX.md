### Commands
```bash
npm install              # Install dependencies
npm run dev             # Start development
npm run build           # Production build
npm run start           # Run production
npm run lint            # Check code
npm run dev:debug       # Debug mode
npm run dev:ui          # Only UI
```

## 🆘 Troubleshooting Guide

### Common Issues & Solutions

| Problem | Solution | Document |
|---------|----------|----------|
| "Cannot find module" | Run `npm install` | QUICK_START.sh |
| Port already in use | Kill process on port | API_KEYS_GUIDE.md |
| Invalid API key | Check key format | API_KEYS_GUIDE.md |
| Agent not responding | Check port 8123 | PERIODIC_TABLE_README.md |
| 3D table doesn't render | Check WebGL support | PERIODIC_TABLE_README.md |
| Database missing | Check periodicTableData.ts | API_DOCUMENTATION.md |
| State not updating | Check CopilotKit config | API_DOCUMENTATION.md |
