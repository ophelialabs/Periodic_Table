## 🌐 API ENDPOINTS

### Available Endpoints
```
GET  http://localhost:5000/           # Main page
GET  http://localhost:5000/api/elements  # All elements
GET  http://localhost:5000/api/element/1  # Element by number
GET  http://localhost:5000/api/element/H  # Element by symbol
```

### Example Usage
```bash
# Get all elements (JSON)
curl http://localhost:5000/api/elements

# Get Hydrogen (element 1)
curl http://localhost:5000/api/element/1

# Pretty print JSON
curl http://localhost:5000/api/elements | python -m json.tool
```

## 🆘 COMMON ISSUES & SOLUTIONS

| Problem | Solution |
|---------|----------|
| Flask not found | `pip install -r requirements.txt` |
| Port 5000 in use | Edit `run.py`, change port |
| Can't connect | Make sure `python run.py` is running |
| 3D models not showing | Check WebGL support, update browser |
| Search not working | Check browser console (F12) |
| Blank page | Refresh page (Ctrl+R or Cmd+R) |
| Data not loading | Verify `PeriodicTableJSON.json` exists |
