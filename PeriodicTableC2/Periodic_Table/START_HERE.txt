🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: Port 5001 already in use
Fix:   lsof -i :5001  →  kill -9 <PID>

Issue: .NET not found
Fix:   Install .NET 8.0 from dotnet.microsoft.com

Issue: Q# compilation errors
Fix:   dotnet build PeriodicTableQuantum/

Issue: CSS not loading
Fix:   dotnet build  →  Hard refresh browser (Cmd+Shift+R)

Issue: Component not found
Fix:   Check namespace in @using directive
       Verify file is in Components folder
