## 🚀 Quick Start

```bash
# 1. Navigate to project
cd PeriodicTableWPF

# 2. Restore dependencies
dotnet restore

# 3. Build solution
dotnet build

# 4. Run application
dotnet run --project PeriodicTableApp

# 5. Try these actions:
#    - Select an element from the list
#    - Click "Simulate Element"
#    - Choose a second element
#    - Click "Simulate Bond"
#    - Watch 3D visualization update!
```

**Time to first run: ~5 minutes**
